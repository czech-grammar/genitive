Masculine Animate​

Hard Consonants → add -a​

Nom.Gen.Example
studentstudentabez studenta
pespsabez psa
bratrbratraod bratra
PetrPetraod Petra
doktordoktorau doktora

Soft Consonants → add -e​

Nom.Gen.Example
mužmužebez muže
učitelučiteleod učitele
otecotceod otce

Masculine Inanimate​

Hard Consonants → add -u​

Nom.Gen.Example
hradhraduz hradu
důmdomuz domu
stůlstoluu stolu
obchodobchodudo obchodu
filmfilmukonec filmu

Soft Consonants → add -e​

Nom.Gen.Example
strojstrojeze stroje
pokojpokojez pokoje
počítačpočítačeu počítače

Feminine​

-a Nouns → -y​

Nom.Gen.Example
ženaženybez ženy
knihaknihyautor knihy
školaškolydo školy
PrahaPrahyz Prahy

-e Nouns → -e (no change)​

Nom.Gen.Example
růžerůžebez růže
restauracerestauracevedle restaurace
práceprácedo práce

Consonant Nouns → -i​

Nom.Gen.Example
věcvěcibez věci
nocnociuprostřed noci
kostkostibez kosti

Neuter​

-o Nouns → -a​

Nom.Gen.Example
městoměstaz města
autoautabarva auta
pivopivasklenice piva
oknooknaz okna

-e Nouns → -e (no change)​

Nom.Gen.Example
mořemořeblízko moře
srdcesrdcez celého srdce
polepoleuprostřed pole

-í Nouns → -í (no change)​

Nom.Gen.Example
nádražínádražíz nádraží
náměstínáměstíuprostřed náměstí
