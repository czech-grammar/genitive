## Quick Reference

### Singular

| Gender | Nominative | Genitive |
|:-------|:-----------|:---------|
| Masc. Animate Hard | student | student**a** |
| Masc. Animate Soft | muž | muž**e** |
| Masc. Inanimate Hard | hrad | hrad**u** |
| Masc. Inanimate Soft | stroj | stroj**e** |
| Feminine -a | žena | žen**y** |
| Feminine -e | růže | růž**e** |
| Feminine cons. | věc | věc**i** |
| Neuter -o | město | měst**a** |
| Neuter -e | moře | moř**e** |
| Neuter -í | nádraží | nádraž**í** |

### Plural

| Gender | Nom. Plural | Gen. Plural |

| Feminine cons. | věci | věc**í** |
