# Genitive Singular Endings

The Genitive singular has more variation than the Accusative, but follows clear patterns once you learn them.

---

## The Big Picture

:::tip Key Patterns
- **Masculine** → mostly **-a** (animate) or **-u** (inanimate)
- **Feminine -a** → **-y** (with palatalization!)
- **Feminine -e** → stays **-e**
- **Neuter -o** → **-a**
- **Neuter -e/-í** → stays the same
:::

---

### Animate - Hard Pattern → **-a**

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| student | student**a** | kniha studenta |
| bratr | bratr**a** | auto bratra |
| otec | otc**e** | dům otce |

| Petr | Petr**a** | sestra Petra |
| pán | pán**a** | dopis pána |
| syn | syn**a** | pokoj syna |

### Animate - Soft Pattern → **-e**

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| muž | muž**e** | práce muže |
| učitel | učitel**e** | kniha učitele |
| přítel | přítel**e** | dům přítele |
| prodavač | prodavač**e** | jméno prodavače |

### Inanimate - Hard Pattern → **-u** (most common)

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| hrad | hrad**u** | okno hradu |
| stůl | stol**u** | noha stolu |
| dům | dom**u** | střecha domu |
| rok | rok**u** | konec roku |
| čaj | čaj**e** | šálek čaje |
| les | les**a** | uprostřed lesa |

:::info Some inanimate nouns use -a
A few masculine inanimate nouns take **-a** instead of **-u**:
- les → les**a** (forest)
- oběd → obě**da** (lunch)
- večer → veče**ra** (evening)
:::

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| stroj | stroj**e** | součást stroje |
| pokoj | pokoj**e** | okno pokoje |
| počítač | počítač**e** | obrazovka počítače |

## Feminine Nouns

### Hard Feminine (-a) → **-y**

The ending **-a** changes to **-y**. Watch for palatalization!

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| žena | žen**y** | dům ženy |
| kniha | knih**y** | autor knihy |
| škola | škol**y** | ředitel školy |
| voda | vod**y** | sklenice vody |
| káva | káv**y** | šálek kávy |
| matka | matk**y** | sestra matky |

#### Palatalization before -y

| Consonant | Change | Example |
|:----------|:-------|:--------|
| k → c | ruka → ruc**y** | bolest ruky |
| h → z | Praha → Pra**hy** | centrum Prahy |
| ch → š | střecha → střec**hy** | oprava střechy |
| g → z | kolega → koleg**y** | kancelář kolegy |
| r → ř | sestra → sestr**y** | pokoj sestry |

Wait - actually for feminine genitive the palatalization is simpler:

:::tip Palatalization in Feminine Genitive
For feminine **-a** nouns, just change **-a** to **-y**:
- žena → ženy
- Praha → Prahy (no consonant change!)
- kniha → knihy
- ruka → ruky

The consonant changes (k→c, h→z) happen in **Locative**, not Genitive!
:::

### Soft Feminine (-e) → **-e** (no change)

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| růže | růž**e** | vůně růže |
| restaurace | restaurac**e** | jméno restaurace |
| ulice | ulic**e** | konec ulice |
| práce | prác**e** | kvalita práce |

### Consonant-ending Feminine → **-i**

| Nominative | Genitive | Example |
|:-----------|:---------|:--------|
| věc | věc**i** | cena věci |
| noc | noc**i** | uprostřed noci |
| kost | kost**i** | barva kosti |
| postel | postel**i** | okraj posteli |
| píseň | písn**ě** | text písně |

## Common Mistakes

:::warning Watch Out!

**❌ kniha student** (nominative, wrong!)
**✅ kniha studenta** (genitive for possession)

---

**❌ centrum města** ✅ (this is correct!)
**❌ centrum město** (nominative, wrong!)

---

**❌ konec roku** ✅ (this is correct!)
**❌ konec roka** (wrong ending for inanimate)
:::
