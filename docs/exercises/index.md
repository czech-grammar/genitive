## Quick Practice: Singular Endings

Put the noun in Genitive:

### Set 1: Masculine

1. bez ___ (student) →
2. z ___ (hrad) →
3. od ___ (bratr) →
4. u ___ (doktor) →
5. vedle ___ (muž) →

<details>
<summary>**Answers**</summary>

1. bez **studenta** (animate → -a)
2. z **hradu** (inanimate hard → -u)
3. od **bratra** (animate → -a)
4. u **doktora** (animate → -a)
5. vedle **muže** (animate soft → -e)

</details>

### Set 2: Feminine

1. bez ___ (žena) →
2. z ___ (Praha) →
3. do ___ (škola) →
4. u ___ (sestra) →
5. vedle ___ (růže) →

<details>
<summary>**Answers**</summary>

1. bez **ženy** (-a → -y)
2. z **Prahy** (-a → -y)
3. do **školy** (-a → -y)
4. u **sestry** (-a → -y)
5. vedle **růže** (-e → -e)

</details>

### Set 3: Neuter

1. z ___ (město) →
2. do ___ (kino) →
3. uprostřed ___ (náměstí) →
4. blízko ___ (moře) →
5. z ___ (nádraží) →

<details>
<summary>**Answers**</summary>

1. z **města** (-o → -a)
2. do **kina** (-o → -a)
3. uprostřed **náměstí** (-í → -í)
4. blízko **moře** (-e → -e)
5. z **nádraží** (-í → -í)

</details>

## Quantity Practice

Use the correct genitive plural:

| Number/Quantity | Noun | Answer |
|:----------------|:-----|:-------|
| pět | student | ? |
| mnoho | kniha | ? |
| kolik | hodina | ? |
| šest | město | ? |
| málo | čas | ? |

<details>
<summary>**Answers**</summary>

| Number/Quantity | Noun | Answer |
|:----------------|:-----|:-------|
| pět | student | pět **studentů** |
| mnoho | kniha | mnoho **knih** |
| kolik | hodina | kolik **hodin** |
| šest | město | šest **měst** |
| málo | čas | málo **času** |

</details>
