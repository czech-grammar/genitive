# Genitive Case Quick Reference

Everything you need on one page. Print this!

---

## The Core Pattern

:::tip Remember This!
- **Masculine animate** → **-a** (hard) or **-e** (soft)
- **Masculine inanimate** → **-u** (hard) or **-e** (soft)
- **Feminine** → **-y** (hard), **-e** (soft), **-i** (consonant)
- **Neuter** → **-a** (hard) or **-e** (soft)
:::

## Numbers with Genitive

| Number | Case | Example |
|:-------|:-----|:--------|
| 1 | Nominative | jeden student |
| 2-4 | Nom. plural | dva studenti |
| 5+ | **Genitive plural** | pět student**ů** |

Quantity words also take genitive:
- **mnoho** lidí (many people)
- **málo** času (little time)
- **kolik** knih? (how many books?)

## Quick Decision Tree

```
Need GENITIVE when:
├── After preposition (z, do, od, bez, u...)
├── Possession (kniha bratra)
├── After 5+ or quantity words (pět studentů)
├── Partitive (sklenice vody)
└── Certain verbs (bát se, ptát se...)

SINGULAR endings:
├── Masculine: -a/-e (animate), -u/-e (inanimate)
├── Feminine: -y, -e, or -i
└── Neuter: -a or -e

PLURAL endings:
├── Masculine: -ů
├── Feminine: zero or -í
└── Neuter: zero or -í
```

---

## The Key Questions

1. **Is it a preposition?** → Check if it takes genitive
2. **Is it possession?** → Use genitive
3. **Is there a number 5+?** → Use genitive plural
4. **Is it a quantity word?** → Use genitive
