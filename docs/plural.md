# Genitive Plural Endings

The Genitive plural is the **most complex** part of Czech noun declension. Different patterns behave very differently - but once you learn them, you'll recognize them everywhere.

---

## The Big Picture

:::warning The Tricky Part
Unlike other cases, the Genitive plural has **four different main endings**:
- **-ů** (masculine)
- **-í** (feminine soft, neuter soft)
- **Zero ending** (many feminine -a and neuter -o nouns!)
- **-í** (some patterns)
:::

---

## Quick Reference

| Gender/Type | Nominative Sg. | Gen. Plural | Example |
|:------------|:---------------|:------------|:--------|
| **Masc. Animate Hard** | student | student**ů** | pět studentů |
| **Masc. Animate Soft** | muž | muž**ů** | pět mužů |
| **Masc. Inanimate** | hrad | hrad**ů** | pět hradů |
| **Feminine -a** | žena | žen (∅) | pět žen |
| **Feminine -e** | růže | růž**í** | pět růží |
| **Feminine cons.** | věc | věc**í** | pět věcí |
| **Neuter -o** | město | měst (∅) | pět měst |
| **Neuter -e** | moře | moř**í** | pět moří |
| **Neuter -í** | nádraží | nádraží | pět nádraží |

## Masculine Nouns → **-ů**

Good news! Almost all masculine nouns use **-ů** in genitive plural.

### Animate - Hard

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| student | student**ů** | pět studentů |
| bratr | bratr**ů** | pět bratrů |
| pes | ps**ů** | pět psů |
| pán | pán**ů** | pět pánů |
| Čech | Čech**ů** | pět Čechů |
| kluk | kluk**ů** | pět kluků |

### Animate - Soft

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| muž | muž**ů** | pět mužů |
| učitel | učitel**ů** | pět učitelů |
| přítel | přítel**ů** | pět přátel |
| prodavač | prodavač**ů** | pět prodavačů |

### Inanimate - Hard

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| hrad | hrad**ů** | pět hradů |
| stůl | stol**ů** | pět stolů |
| dům | dom**ů** | pět domů |
| rok | rok**ů** | pět roků |
| měsíc | měsíc**ů** | pět měsíců |

### Inanimate - Soft

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| stroj | stroj**ů** | pět strojů |
| pokoj | pokoj**ů** | pět pokojů |
| počítač | počítač**ů** | pět počítačů |

:::tip Easy Rule for Masculine
**All masculine → -ů** (with possible vowel changes like ů→o)
:::

## Feminine Nouns

### Feminine -a → **Zero Ending** (∅)

This is the famous "fleeting vowel" pattern. The **-a** disappears, often with vowel insertion.

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| žena | žen | pět žen |
| kniha | knih | pět knih |
| škola | škol | pět škol |
| hodina | hodin | pět hodin |
| minuta | minut | pět minut |
| koruna | korun | pět korun |

#### With Inserted Vowel

When consonant clusters would be hard to pronounce, a vowel is inserted:

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| sestra | sester | pět sester |
| hra | her | pět her |
| dcera | dcer | pět dcer |

:::info Common Pattern
Most feminine **-a** nouns: just remove the **-a**!
- žena → žen
- kniha → knih
- hodina → hodin
:::

### Feminine -e → **-í**

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| růže | růž**í** | pět růží |
| ulice | ulic**í** | pět ulic |
| restaurace | restaurac**í** | pět restaurací |
| práce | prác**í** | pět prací |

### Feminine Consonant → **-í**

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| věc | věc**í** | pět věcí |
| noc | noc**í** | pět nocí |
| kost | kost**í** | pět kostí |
| postel | postel**í** | pět postelí |
| píseň | písn**í** | pět písní |

## Neuter Nouns

### Neuter -o → **Zero Ending** (∅)

Like feminine -a, many neuter -o nouns lose their ending.

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| město | měst | pět měst |
| slovo | slov | pět slov |
| místo | míst | pět míst |
| jablko | jablek | pět jablek |
| okno | oken | pět oken |
| pivo | piv | pět piv |

#### With Inserted Vowel

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| jablko | jablek | pět jablek |
| okno | oken | pět oken |
| auto | aut | pět aut |

### Neuter -e → **-í**

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| moře | moř**í** | pět moří |
| pole | pol**í** | pět polí |
| srdce | srdc**í** | pět srdcí |

### Neuter -í → **-í** (no change)

| Nominative Sg. | Gen. Plural | Example |
|:---------------|:------------|:--------|
| nádraží | nádraží | pět nádraží |
| náměstí | náměstí | pět náměstí |
| stavení | stavení | pět stavení |

## Summary by Ending

| Ending | Used For | Examples |
|:-------|:---------|:---------|
| **-ů** | All masculine | studentů, mužů, domů |
| **∅ (zero)** | Fem. -a, Neut. -o | žen, knih, měst, slov |
| **-í** | Fem. -e, Fem. cons., Neut. -e | růží, nocí, moří |

## Numbers with Genitive Plural

The genitive plural is required after numbers 5 and higher:

| Number | Example |
|:-------|:--------|
| 5+ | pět studentů, šest žen, sedm měst |
| kolik | Kolik máš knih? |
| mnoho | mnoho lidí |
| málo | málo času |
| hodně | hodně peněz |
| několik | několik minut |

## Common Mistakes

:::warning Watch Out!

**❌ pět student** (nominative!)
**✅ pět studentů** (genitive plural after 5+)

---

**❌ mnoho knih** ✅ (this is correct!)
**❌ mnoho knihy** (wrong - not genitive plural)

---

**❌ pět města** (genitive singular!)
**✅ pět měst** (genitive plural)
:::

---

## Memory Tricks

:::tip Patterns to Remember
1. **Masculine** → always **-ů** (easy!)
2. **Feminine -a** → lose the -a (žena → žen)
3. **Feminine -e** → change to **-í** (růže → růží)
4. **Neuter -o** → lose the -o (město → měst)
5. **Soft endings** → usually **-í**
:::
