Genitive Singular Endings

The Genitive singular has more variation than the Accusative, but follows clear patterns once you learn them.

The Big Picture​

Key Patterns
  • Masculine → mostly -a (animate) or -u (inanimate)
  • Feminine -a → -y (with palatalization!)
  • Feminine -e → stays -e
  • Neuter -o → -a
  • Neuter -e/-í → stays the same

Some inanimate nouns use -a

A few masculine inanimate nouns take -a instead of -u:

  • les → lesa (forest)
  • oběd → oběda (lunch)
  • večer → večera (evening)

Feminine Nouns​

Hard Feminine (-a) → -y​

The ending -a changes to -y. Watch for palatalization!

NominativeGenitiveExample

Palatalization before -y​

ConsonantChangeExample
k → cruka → rucybolest ruky
h → zPraha → Prahycentrum Prahy
ch → šstřecha → střechyoprava střechy
g → zkolega → kolegykancelář kolegy
r → řsestra → sestrypokoj sestry

Wait - actually for feminine genitive the palatalization is simpler:

Palatalization in Feminine Genitive

For feminine -a nouns, just change -a to -y:

  • žena → ženy
  • Praha → Prahy (no consonant change!)
  • kniha → knihy
  • ruka → ruky

The consonant changes (k→c, h→z) happen in Locative, not Genitive!

Practice​

Put the noun in Genitive:

  1. kniha ___ (student) →
  2. okno ___ (dům) →
  3. šálek ___ (káva) →
  4. centrum ___ (Praha) →
  5. jméno ___ (pes) →
  6. konec ___ (rok) →
  7. barva ___ (auto) →
  8. pokoj ___ (sestra) →
  9. dopis od ___ (učitel) →
  10. sklenice ___ (voda) →
Check Answers
  1. kniha studenta (masc. animate → -a)
  2. okno domu (masc. inanimate → -u)
  3. šálek kávy (fem. -a → -y)
  4. centrum Prahy (fem. -a → -y)
  5. jméno psa (masc. animate → -a)
  6. konec roku (masc. inanimate → -u)
  7. barva auta (neuter -o → -a)
  8. pokoj sestry (fem. -a → -y)
  9. dopis od učitele (masc. animate soft → -e)
  10. sklenice vody (fem. -a → -y)

Common Mistakes​

Watch Out!

❌ kniha student (nominative, wrong!) ✅ kniha studenta (genitive for possession)

❌ centrum města ✅ (this is correct!) ❌ centrum město (nominative, wrong!)

❌ konec roku ✅ (this is correct!) ❌ konec roka (wrong ending for inanimate)
